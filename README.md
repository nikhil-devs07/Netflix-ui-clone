# Netflix UI Clone

This is a Netflix homepage UI clone made using HTML and CSS.

## About
This project is only the front-end UI of Netflix.  
It is made for practice and learning web development.

It does not include any backend or real functionality like login, database, or video streaming.

## Features
- Responsive design
- Netflix-like layout
- Clean UI design
- Built using only HTML and CSS

## Purpose
Just a practice project to improve frontend skills and understand layout design.

## Note
This is not an official Netflix project. It is only a UI clone made for learning purposes.
